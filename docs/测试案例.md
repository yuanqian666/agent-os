## 案例 4：可视化面板（Web）

**目的**：验证图形化界面——沙箱树动态生长、日志流、运行历史。

### 步骤（双进程模式）

```bash
# 终端 A：启动系统
python -m agent_os.interface.cli

# 终端 B：启动独立面板（文件模式）
python -m agent_os.interface.web --port 8720
```

浏览器打开 `http://127.0.0.1:8720/`，在终端 A 提交案例 1 的任务。

### 验证点

| # | 验证项 | 预期 |
|---|---|---|
| 1 | 沙箱树 | 初始 5 节点（root + 4 HAA）；任务中族系子出现（状态 idle→running→completed）；任务后消失 |
| 2 | 日志流 | 自动滚动，TASK 蓝色/STATUS 绿色/ERROR 红色 |
| 3 | 运行历史 | 表格出现本次任务（时间/结果/族系/能力） |
| 4 | 状态栏 | 沙箱数/root 状态/日志条数实时变化 |

## 已知问题（不影响主流程）

1. **`out/system.log` 偶发双写同一行**：log_haa 单次执行但文件出现两行相同内容（写入层竞态，疑似文件句柄/时序）；无实质影响，根治列入 V1.1（进程级单例锁）。
2. **子进程日志可见性**：Windows 上曾因 `CREATE_NO_WINDOW` 静默丢失（已修复于 `279c988`）；若日志再次不可见，检查 `supervisor._spawn` 的 Popen 是否误加该 flag。
