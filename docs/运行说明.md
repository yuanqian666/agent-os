# Agent OS — 运行说明（中文）

> 本说明面向想要克隆并运行本项目的读者。完整设计见根目录 `README.md`。

---

## 1. 环境要求

| 依赖 | 版本要求 | 说明 |
|---|---|---|
| Python | 3.10+（开发环境 3.11.9 验证通过） | 3.12/3.13 未验证，如有问题请提 Issue |
| watchdog | 6.0.0 | 文件系统事件监听（沙箱通信驱动） |
| pytest | 任意较新版本 | 仅测试需要 |
| 操作系统 | Windows / Linux | 沙箱为"进程 + 目录"模型，跨平台 |

无 LLM / GPU / 网络 API 依赖——**零 LLM，纯确定性实现**。

## 4. 运行演示（最快体验）

```bash
python scripts/run_demo.py
```

自动执行演示任务 **"Calculate (5+7)*3 and save result to disk"**，控制台会显示：

1. OS 启动，Root 直连持久 HAA（math / disk / file_read / log）
2. 界面层提交任务 → Root 分析需求基因 → **无性繁殖**出 4 个族系子沙箱
3. 各子 Agent 经 HAA 执行（读文件 → 计算 → 写盘 → 记日志）
4. 结果沿族系上抛 → Root 聚合 → **OS 销毁整棵 Agent 树**（验证无状态残留）

落盘结果在 `out/` 目录（如 `out/t1.txt`）。

---

## 5. 交互式 CLI + Web 可视化面板

```bash
python -m agent_os.interface.cli
```

启动后浏览器打开 **http://127.0.0.1:8710/** ，实时查看：

- 自上而下 Agent 树（root 在顶，连线向下）
- 繁殖后 HAA 动态挂载到携带其基因的族系子下（符合公链语义）
- 已销毁节点灰显保留 15s（任务生命周期可见）

CLI 支持两种输入：

```
# 演示句（规则解析）
> Calculate 5+7 and save result to disk

# 结构化 JSON 任务
> {"task_id":"t2","description":"write hello to disk","parameters":{"content":"hello","save":true}}
```

`exit` 退出。常用参数：`--no-web` 关闭面板；`--verbose` 显示全部日志（含 EVENT 文件事件）。

## 8. 常见问题

**Q1：`pip install -e .` 后 `python -m agent_os` 报找不到模块？**
检查是否在仓库根目录执行；确认 Python 版本 ≥ 3.10。

**Q2：Web 面板打不开？**
确认端口 8710 未被占用；或改用 `--no-web` 只跑 CLI。

**Q3：运行时 `sandbox_root/` 内容很多？**
正常——那是沙箱运行时目录，任务结束后 OS 会自动清空（成功标准第 6 条）。不要手动删除正在运行时的目录。

**Q4：在 Linux 上运行有什么不同？**
无。实现使用标准库 `multiprocessing` + watchdog，跨平台行为一致。ACL 判定由 OS 层进程注册表完成（不依赖 FS 权限），Windows/Linux 表现相同。

**Q5：演示输出和预期不符？**
先跑 `python -m pytest tests/ -v` 确认 19 个用例全绿，再提 Issue 并附上控制台日志。

## 9. 项目结构速览

```
agent-os/
├── README.md               # 技术博客格式项目报告（先读这个）
├── pyproject.toml          # 包定义
├── requirements.txt        # 依赖：watchdog、pytest
├── src/agent_os/
│   ├── constants.py        # 沙箱契约常量（目录/字段/状态/基因）
│   ├── schemas.py          # task/status/manifest/genome JSON 校验
│   ├── os_layer/           # L4：supervisor（沙箱生命周期/ACL）/ provisioner / client
│   ├── haa/                # L3：math / disk / file_read / log 四个 HAA
│   ├── agent/              # L2：runtime / task_loop / router / reproduction / skill_table
│   ├── interface/          # L1：cli（演示句解析 + JSON）+ web 可视化面板
│   ├── lifecycle/          # bootstrap：OS → HAAs → 界面层 → Root
│   └── utils/              # watchers（watchdog 封装）/ jsonio（原子读写）/ logger
├── scripts/run_demo.py     # 一键演示
├── tests/                  # 19 个测试用例
└── docs/                   # 规格书 / 构想 / 公理 / 测试手册 / 存档说明
```
